# External Handoff V0

This directory contains Ming Workbench's product-level intake contract for user-approved cross-product Handoff.

It is intentionally **not** a MingOS Core schema yet. The contract must first be proven in real product use.

Current producer under validation: `YuemingHub/Return-to-oneself`.

Key rule: unknown/extra fields are rejected rather than ignored, so private source-product context cannot silently cross into Ming.
